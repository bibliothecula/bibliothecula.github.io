# Cell Organelles 
## Overview
An organelle is a specialized subunit, within a biological cell, that has a specific function (Source: [_Wikipedia_](https://en.wikipedia.org/wiki/Organelle))
___
## Etymology

**ORGANELLE (n.)** 
```
"Small specialized structure within a cell," 
1910, from Modern Latin organella (1909), 
a diminutive from Latin organum "instrument," 
in Medieval Latin "organ of the body" (see organ). 
```
(Source: [_Etymonline_](https://www.etymonline.com/word/organelle))
